# 《03:00の展覧会》ver.5

React + Vite + JavaScriptで制作した、スマートフォン向けWebホラーゲームです。

## ver.5の主な変更

- ユーザーが修正した会話データをそのまま維持
- 春日さんの立ち絵素材から大きな透明余白を除去
- 会話中の立ち絵を拡大し、スマートフォンでも顔と表情を確認しやすく調整
- 画面の左右によって立ち絵を配置し、会話欄の後ろに自然に収まるよう調整
- エピローグの後、プレイヤー向け警告画面の前にEND画面を追加
- END画面に「作品の別の姿」の素材提供者への感謝メッセージを掲載
- END画面の後に画面が激しく乱れるグリッチ演出を追加
- グリッチ演出後、従来の赤文字のスマホ警告画面へ自動遷移

## エンディングの流れ

1. 深夜巡回クリア
2. 春日さんが自宅で目を覚ますエピローグ
3. END・謝辞画面
4. 画面のグリッチ／ノイズ演出
5. プレイヤー名入りの赤文字警告画面

## 起動

```bash
npm install
npm run dev
```

本番用ビルド：

```bash
npm run build
```

## 背景画像の場所

`public/assets/backgrounds/`

同じファイル名・比率の画像に置き換えれば、別の画像生成AIやCanvaで作成した背景へ差し替えられます。
